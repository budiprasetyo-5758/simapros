--- KEBUTUHAN FITUR & UI BARU ---
Sidebar menu: "Follow Up" (khusus super_admin). Tampilan awal berisi 3 Folder Card: Rapimtas, Rapim, Others.
Ketika folder diklik, masuk ke halaman detail kategori yang memiliki 3 TAB UTAMA:

1. TAB "MEETINGS" (Default Tab)
- Berisi daftar meeting dalam bentuk CARD.
- Tombol "Tambah Meeting" ada di sini.
- Form Tambah Meeting:
  a. Tanggal Meeting (Date picker, wajib).
  b. Nama Meeting (HANYA MUNCUL dan wajib jika berada di folder "Others". Untuk Rapimtas/Rapim, sembunyikan field ini dan biarkan null/kosong).
  c. Tasks (Dynamic list): Field-nya hanya "Nama Task", "Due Date" (Date picker), dan "PIC" (Text). TIDAK ADA upload file untuk task di form ini.
  d. Upload File Notulensi.
  e. Upload File Pendukung.
- Tampilan Card Meeting: Menampilkan info meeting, daftar task dalam bentuk list biasa (hanya menampilkan nama, PIC, due date, status selesai), dan tombol download untuk file notulensi & pendukung. Di tab ini, task TIDAK BISA di-checklist selesai.

2. TAB "TASK MEETING"
- Berisi Data Table dari semua task yang ada di dalam kategori/folder tersebut.
- Kolom Tabel: Task | PIC | Due Date | File | Action (Checkbox).
- Tabel harus bisa di-sort (diurutkan) berdasarkan setiap kolom.
- Kolom "File" berisi tombol/link untuk melihat file pendukung/notulensi dari meeting yang terkait dengan task tersebut.
- Di tab Inilah user bisa MENCENTANG (Checklist) task menjadi "Selesai".

3. TAB "FILE REPOSITORY"
- Di dalam tab ini, bagi lagi menjadi 2 Sub-Tab: "File Notulensi" dan "File Pendukung".
- Berisi daftar file sesuai kategorinya, lengkap dengan metadata (nama file, tanggal upload, dari meeting mana, dan tombol download).
